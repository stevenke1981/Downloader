# 桌面控制使用說明

## 定位已完成檔案

單擊已完成的下載列，或選取後按「開啟資料夾」。Windows 會透過系統檔案總管開啟實際父目錄並選取檔案；macOS 使用 Finder 定位；Linux 開啟父目錄。這些操作不會執行下載的檔案。

尚未完成或失敗的下載仍可選取查看詳情；按「開啟資料夾」會顯示尚未完成提示。檔案移動、刪除、變成目錄或檔案管理器開啟失敗時，主視窗顯示原因，可按「關閉提示」。程式不會猜測移動後的檔案位置。

## Windows 系統匣

按「縮小至系統匣」隱藏主視窗，下載持續執行。左鍵點系統匣圖示可還原；右鍵選單提供總下載狀態、還原主視窗、精簡視窗與退出。Windows 可能將圖示放在工作列的隱藏圖示區。

再次啟動 Downloader 也會透過原本的單一執行個體 IPC 還原主視窗。系統匣無法建立時按鈕停用，不會把視窗藏起來。其他平台的系統匣按鈕目前停用，仍可使用精簡視窗和作業系統的一般最小化。

主視窗右上角關閉和「退出」都代表結束程式。有排隊、下載中或驗證中的項目時，會顯示退出確認；取消後繼續執行，確認後沿用下載核心的保存／中止程序。下次啟動可續傳，實際續傳支援仍取決於伺服器。

## 精簡視窗

按「精簡視窗」可查看所有項目的進度與總速度，與主視窗共用下載管理器，不會啟動另一個背景程式。按「還原主視窗」或關閉精簡視窗，會回到主視窗。

「保持置頂」預設關閉，僅在本次執行由使用者勾選時生效。不會新增開機啟動或常駐服務。主視窗的分類篩選不會隱藏精簡視窗中的其他下載。

## 驗收界線

本次新增路徑與生命週期回歸測試，使用暫存目錄、自製資料與本機 HTTP fixture，不讀取私人下載歷史。內部測試後端驗證反覆切換與背景下載，不能替代 Windows 檔案總管、系統匣選單和置頂的實機互動驗證。實際執行結果另記於發布驗收紀錄。
