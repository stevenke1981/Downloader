# Adviser review of 0.7 core (Fable 5.2) — findings to fix

1 HIGH engine.rs:379-403 + 143-153: Overwrite destroys existing file when verification fails (publish renames .part over a.iso, verify fails, final_path deleted). Fix: under Overwrite with an existing target, publish to a unique_name first; replace onto the wanted name in engine::run only after verify_task Ok; mismatch deletes only the new file.
2 HIGH engine.rs:235-241, util.rs:202: Skip lets two tasks share a .part (Skip only checks dir/name). Fix: Skip/Overwrite with an existing <name>.part => Rename (or file exists: error for Skip).
3 HIGH engine.rs:284-301: disk precheck rejects resuming a preallocated download (set_len already reserved space). Fix: need = total.saturating_sub(current .part length), or check only when fresh.
4 MED remote.rs:237: /import 1 MiB limit compares path including query; dlxctl sends /import?start=.. Fix: compare path.split('?').next().
5 MED modules/mod.rs:262-264,297-302,327: prepare never clears task.resolved_url (revoked/disabled/skip module keeps steering); module headers merged into persisted t.headers leak to the original site after restart; contradicts docs/modules.md:80. Fix: resolved_url=None at top of prepare before early returns; keep module headers in a #[serde(skip)] task field (e.g. Task.module_headers, owner of task.rs adds it) used only with resolved_url.
6 MED engine/worker.rs:56,69-71: custom headers can follow a cross-origin redirect in segment workers (ctx.client auto-follows). Fix: when headers non-empty use ctx.protocol_client (no redirects) and treat 3xx as retry/re-probe.
7 MED bin/dlx.rs:196: --modules-dir forces modules.enabled=true, ignoring the global off switch; approval not bound to folder. Fix: drop the override; load only from modules_dir() or document that approval binds id+manifest hash not folder (prefer: approval only valid for modules_dir()).
8 MED manager.rs:168, bin/dlxctl/modules.rs:101-122: dlxctl revoke/disable undone by running app's next settings save. Fix: set_settings intersects in-memory approvals with those on disk (on-disk revoke wins, and on-disk enabled=false wins if changed externally) + docs/cli.md warning.
9 LOW protocols/mod.rs:186-199: Overwrite removes destination before rename (rename failure loses old file); Skip evaluated after whole transfer for FTP/torrent/media while docs/cli.md:41 says before. Fix: drop remove_file (rename replaces files); check Skip before protocol.download when the name is known, else fix doc.
10 LOW util.rs:251, engine.rs:73: error classes skewed by URL text (reqwest "for url (...?token=401)" => auth). Fix: e.without_url() in err_str; align docs/cli.md exit-code table with error_code mapping (timeout=network=3; HTTP 401/403 classification consistent).
11 LOW manager.rs:215-226, dlxctl/modules.rs:36-51: approval hashes unvalidated unbounded file. Fix: call modules::manifest_hash (validates, caps size) in both; ideally accept expected sha and reject mismatch.
12 LOW modules/external.rs:61-69, scheduler.rs:134-141: hook killed at first stdout line; failed event from Skip carries user's pre-existing file path. Fix: hooks wait for exit/timeout (stdout drained & discarded); HookEvent path only when the task created the file (else empty/None — keep type, use empty PathBuf or make path Option if owner agrees; document).
