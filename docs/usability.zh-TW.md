# 易用性功能說明（0.6.0）

本文說明 0.6.0 新增的搜尋、右鍵選單、快捷鍵與清除功能。其他操作請見 [README](../README.md) 與 [桌面控制說明](desktop-controls.zh-TW.md)。

## 搜尋下載

- 清單上方的搜尋框可依**名稱或網址**篩選，不分大小寫，輸入時即時更新。
- 按 `Ctrl+F` 可直接跳到搜尋框（清單中有下載時才會生效）。
- 按 `Esc` 或搜尋框旁的清除按鈕可清空搜尋。
- 搜尋結果為空時，畫面會提示「請嘗試其他搜尋字詞，或返回全部下載」。
- 搜尋與側邊欄篩選（全部／進行中／已完成／分類）可以疊加使用。

## 右鍵選單

在下載項目上按滑鼠右鍵會先選取該列，再顯示選單：

| 選單項目 | 何時可用 | 說明 |
|---|---|---|
| 開始／繼續 | 可開始或繼續的下載 | 開始或繼續這筆下載 |
| 暫停 | 排隊中或下載中 | 暫停這筆下載 |
| 開啟檔案 | 已完成 | 用系統預設程式開啟檔案（規則見下方） |
| 開啟資料夾 | 已完成 | 在檔案總管中顯示檔案所在的資料夾 |
| 複製網址 | 一律可用 | 把下載網址複製到剪貼簿，並顯示「已複製網址」提示 |
| 刪除… | 一律可用 | 開啟刪除確認，可選擇是否同時刪除磁碟上的檔案 |

「開啟檔案」只會用預設程式開啟常見的影音、文件、圖片、壓縮檔與文字檔。其他類型（例如程式、指令碼）不會被執行，而會改為在資料夾中顯示。

## 清除已完成

- 工具列的「清除已完成」會把清單中**已完成**的下載移出清單。
- 它只清除**目前畫面上可見**的已完成下載，會遵守側邊欄篩選與搜尋條件。例如選了「已完成」或輸入搜尋字詞後，只會清除符合條件的那些。
- **檔案不會被刪除**，仍保留在磁碟上。清除後會顯示提示，例如「已從清單移除的已完成下載：N。檔案仍保留在磁碟上。」
- 若要連同檔案一起刪除，請使用「刪除…」並勾選「同時從磁碟刪除檔案」。

## 快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl+N` | 新增下載 |
| `Ctrl+V` | 開啟新增視窗，並先填入剪貼簿中的下載連結 |
| `Ctrl+F` | 跳到搜尋框（清單中有下載時） |
| `Ctrl+,` | 開啟設定 |
| `↑` / `↓` | 在目前可見的清單中上下移動選取 |
| `Space` | 開始選取的下載；若不能開始，則暫停 |
| `Delete` | 刪除選取的下載（開啟刪除確認） |
| `Enter` | 開啟選取的已完成下載檔案（搜尋框有輸入焦點時不觸發） |
| `Esc` | 搜尋框有文字時清空搜尋；關閉開啟中的對話框 |
| `Ctrl+Enter` | 在新增視窗中送出（網址欄有焦點時，單按 Enter 仍是換行） |
| `Ctrl+Tab` | 在設定視窗中切換分頁 |

## 新增下載時自動帶入剪貼簿

按「新增」或 `Ctrl+V` 時，若剪貼簿中有下載連結，新增視窗會先把這些連結填入網址欄，省去手動貼上。剪貼簿沒有連結時，視窗維持空白。

## 程式與指令碼

為了安全，程式、指令碼與其他不常見的檔案類型不會被直接執行。「開啟檔案」對這類檔案會改為在資料夾中顯示，提示文字為「此檔案類型會在資料夾中顯示，而不會直接開啟。」

## 狀態列按鈕

「精簡視窗」、「縮小至系統匣」與「退出」已移到視窗底部的狀態列。「縮小至系統匣」目前僅 Windows 可用；其他平台可改用精簡視窗。

## 提示訊息顏色

視窗上方的提示列依內容分為兩種：

- **一般資訊**：淡藍色底，例如「已複製網址」、「已新增 N 個下載」。
- **錯誤**：淡紅色底、紅色文字，例如「無法開啟檔案位置」。

只有錯誤會使用紅色。提示列右側的「關閉提示」可以收起提示。

## 疑難排解

- **搜尋不到某筆下載**：確認側邊欄沒有停在會隱藏它的分類，並清空搜尋框後再試。
- **清除已完成後檔案還在**：這是預期行為，清除只影響清單。
- **「開啟檔案」沒有反應或只開資料夾**：該檔案類型不在可直接開啟的清單中，或檔案已被移動或刪除。
- **「開啟資料夾」是灰色的**：只有已完成的下載可以開啟資料夾。
